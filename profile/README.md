# 🌟 솔빗(Solvit)

> _"Uncomfortable? We'll solve it!"_

---

## 💡 팀 소개

**솔빗(Solvit)**은  
세상의 **불편함을 발견하고, 해결하는 팀**입니다.

작은 문제부터 큰 과제까지,  
불편한 점이 있다면 솔빗이 **직접 고민하고, 개발로 해결**합니다.

> 팀 이름 'Solvit'은 "Solve it"에서 비롯되었으며,  
> _"불편함을 해결하자"_는 우리의 철학을 담고 있습니다.

---

## 🎯 우리의 슬로건

> _"Uncomfortable? We'll solve it!"_

- 불편한 점이 있다면?
- 새로운 아이디어가 필요하다면?
- 해결이 필요할 때?

👉 솔빗이 **기획부터 개발까지 함께합니다.**
